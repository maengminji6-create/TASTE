CODE GUIDE

어떤 코드가 화면의 어디를 만드나요?

취향수집소 상세페이지와 QR 기록 페이지를 이루는 파일, 그리고 각 화면 영역을 만드는 HTML · CSS · JavaScript를 짝지어 정리했어요. 표의 #아이디를 상세페이지 주소 뒤에 붙이면 그 영역으로 바로 이동해요.

1파일 구조와 역할

HTML은 무엇이 있는지, CSS는 어떻게 보이는지, JavaScript는 눌렀을 때 무엇이 바뀌는지를 맡아요.

휴대폰에서 QR이 열리려면 사이트가 인터넷 주소로 열려 있어야 해요. GitHub Pages에 올린 주소(https://아이디.github.io/TASTE/)로 열면 renderQR()이 그 주소를 그대로 QR로 만들어요. PC에서 파일로 열 때는 js/config.js의 archiveBaseUrl에 그 주소를 적으면 돼요. 올리는 방법은 readme.md에 있어요. 기록은 서버로 보내지 않고 각 휴대폰에만 저장돼요.
